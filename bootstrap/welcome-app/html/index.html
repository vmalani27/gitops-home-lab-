Welcome to Your Local DevOps Engineering Lab

A hardened local Kubernetes playground powered by Minikube, Ingress-NGINX, and mkcert wildcard TLS.

🎯 What is this Cluster?

You are currently accessing this cluster securely over HTTPS at https://links.test. This lab is structured to replicate production cloud workflows inside your local machine using strict resource constraints, trusted TLS certificates, and a GitOps-first pattern.

Host Target
Windows 11 + WSL2
Ingress Controller
NGINX (Port 443 TLS)
TLS Authority
mkcert (*.links.test)
Memory Capped
4 GB / 3 vCPUs

🗺️ Learning Journey & Roadmap

Here is how this environment evolves from this initial bootstrap screen into a full GitOps platform:

  • Step 1 (Active)
    Bootstrap Cluster & TLS Baseline
    Minikube launched, Ingress controller active, wildcard certificates mounted, and verified end-to-end.
  • Step 2 (Next)
    GitOps Engine (ArgoCD "App of Apps")
    Installing ArgoCD into argocd namespace and pointing root applications to the Git repository.
  • Step 3
    Stateful Data Layer (PostgreSQL)
    Deploying PostgreSQL StatefulSets with persistent Minikube storage in postgresql namespace.
  • Step 4
    Python Microservice (URL Shortener)
    Deploying your Clean Architecture API to replace this landing page at links.test with automatic database migrations and health probes.
