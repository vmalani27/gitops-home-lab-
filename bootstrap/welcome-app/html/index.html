Minikube · Kubernetes v1.37

A small place to build and break things

Hey, welcome to the lab.

This is my little Kubernetes setup. I’m using it to learn the whole trip from code to a running service: build it, deploy it, route traffic to it, and figure out what happens when something goes wrong. It all stays on my machine for now, so I can try things without needing a cloud environment.

You’re looking at the temporary default landing page. The plan is to replace this placeholder once the first production service is ready.

A few things are already in place

The local hostname resolves, HTTPS reaches the cluster, and NGINX routes the request here. I used mkcert for the local certificate, so the browser can trust the connection on this machine. That’s the basic plumbing sorted; now I can focus on the apps.

Cluster
Minikube (Docker driver)
Resources
3 vCPUs · 4 GB RAM
Traffic
NGINX Ingress · HTTPS
Local certificate
mkcert wildcard TLS

What I’m working on next

I’m trying to build this in a sensible order instead of installing tools just to have them. First I want deployments coming from Git, then a database, and then an app that ties it together.

  1. 01
    Get Argo CD running The idea is to keep the desired setup in Git and let Argo CD keep the cluster in sync, rather than applying every change by hand.
  2. 02
    Give the apps somewhere to keep data I’ll add PostgreSQL with persistent storage, so subsequent services have somewhere reliable to persist relational data.
  3. 03
    Deploy the first microservice A containerized backend API to practise automated testing, database migrations, health probes, and the full deploy-from-Git workflow.

Want to have a look around?

These are the commands I usually start with from the terminal when I want to see what’s happening inside the cluster.

See what’s running and how it’s exposed.

kubectl get pods,svc,ingress -A

Check the node Minikube is running.

kubectl get nodes -o wide

Take a look at the local TLS secret.

kubectl get secret wildcard-links-test-tls -n cert-manager
